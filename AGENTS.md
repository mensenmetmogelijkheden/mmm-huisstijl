# Instructions for AI agents

This repository holds the brand identity and brand voice of Stichting Mensen Met Mogelijkheden (MMM) as a skill.

- When you make anything for MMM (text, design, document, presentation, web page, social post): read and follow `skills/mmm-huisstijl/SKILL.md` and the reference files it points to. The guidelines are in Dutch; write MMM content in Dutch.
- When you work on this repository itself: `skills/mmm-huisstijl/tokens/tokens.json` is the source; regenerate `tokens.css` with `python3 tools/tokens-to-css.py`.
- This repository is public. Code, comments and commit messages in English. The README files are in Dutch on purpose: their readers are MMM staff. Never add secrets, personal data or internal figures; mention no other repositories in commits or pull requests.
