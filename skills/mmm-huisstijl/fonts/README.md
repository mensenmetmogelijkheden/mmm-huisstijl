# Letters

Alle drie de letters vallen onder de SIL Open Font License 1.1: vrij te gebruiken, ook in drukwerk, op de website en in documenten. De licentieteksten staan in de `OFL-*.txt`-bestanden in deze map en horen bij de letters te blijven.

| Bestand | Letter | Waarvoor |
| --- | --- | --- |
| `titillium-web-latin-600.woff2`, `-700.woff2` | Titillium Web | Naam, slogan, titels |
| `nunito-latin.woff2` | Nunito (variabel, 200-1000) | Tussenkoppen, knoppen, citaten |
| `atkinson-hyperlegible-next-latin.woff2` | Atkinson Hyperlegible Next (variabel, 200-800) | Lopende tekst |

De webletters komen uit de pakketten `@fontsource-variable/*` 5.3.0 (alleen Latijnse tekens, genoeg voor Nederlands). Host ze zelf; laad ze op websites van MMM niet via Google Fonts (privacy).

## Voor Word en PowerPoint: `ttf/`

In de map `ttf/` staan dezelfde letters als installeerbare bestanden, in de gewichten die de sjablonen gebruiken: Atkinson Hyperlegible Next Regular en Bold, Nunito Regular, Bold en ExtraBold (in Office: "Nunito ExtraBold"), Titillium Web SemiBold en Bold. Ze zijn omgezet uit de webletters hierboven. Dubbelklik en kies Installeren, of rol ze uit via Intune.
